태그 조건은 없다. 이 스킬은 요청한 플레이어 자신의 메모리만 다룬다.

- "뭐 기억해?"에는 `view`를 쓴다. 전문은 본인에게만 보내고(슬래시는 본인에게만 보이는 메시지, 멘션은 DM)
  채널에 읽어 주지 않는다. 답에서는 보냈다는 것과 줄 수 정도만 말한다.
- 지울 내용이 애매하면 어느 항목인지 확인하고 `forget`을 부른다. `what`에는 지울 줄의 내용을 준다.
  호칭을 지울 때는 `what`에 "호칭"이라고 준다. 맞는 줄이 없다는 오류가 오면 오류에 적힌 줄 중에서 다시 고른다.
- "전부 잊어 줘"처럼 전체를 지울 때만 `what`을 비운다.
- 지운 내용을 다시 기억하지 않는다. 지운 항목은 자동 요약도 되살리지 않는다.
- 자동 저장을 끄면 새 대화를 요약해 기억하지 않는다. 이미 기억한 내용은 남고 계속 쓰인다. 완전히 없애려면
  `forget`으로 전부 지워야 한다고 알려 준다.
- "이거 기억해 줘"는 이 스킬이 아니라 `remember`가 처리한다.
