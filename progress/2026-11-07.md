## 후보곡이 `find_songs` 표를 받는다 (4단계, 사용자 승인 "ㄱㄱ")
- `candidates`는 상수 범위만 받아 "레벨 14 곡 중 후보곡"·"신곡 중 후보곡"의 조건을 조용히 버렸다. 선택 인자 `table`을 더하고 `records.candidates(charts=...)`가 그 (곡, 채보 종류, 난이도) 안에서만 고른다.
- 평가(`--repeat 3`): 시나리오 54건 실패 0. 후보곡/레벨·신곡 시나리오는 `find_songs → candidates`를 꼭 부르게 검사를 더했고 6/6 통과.
- 발견(미해결): 평가 플레이어는 기록이 없어 후보곡이 0건이면 표가 안 나오는데, 그때 앞서 만든 `find_songs` 표가 "보인 표"로 나간다(마지막 표를 보이는 코어 규칙). 운영에서도 후보곡이 0건이면 검색 목록이 "후보 없음"과 함께 보일 수 있다.
- examples 실패 21: 이전과 같은 오해석(web-qa 끄기·"12월 31일까지 17.00 목표"·레이팅표 그림·약속 vs remember·"방금 그 표"·시험용 스킬 예시)에, "15.0~15.3 마스 중 SSS 안 된 거 투두" 2/3(검색만 하고 `add_todos` 안 부름), 재킷 그림 네트워크 실패 1, "15.0 마스 곡 상수표로 만들어 줘"가 그림 없이 표만 1(질문에 "그림"이 없어 오답이라 보기 어렵다).

## 상수 범위는 남기고 표와 같이 받으면 둘 다 적용 (사용자 결정 "B", 5단계 대체)
- 사용자 질문 "3/4단계에서 왜 상수 범위는 남겼어?"에 대한 답: 따로 검토한 결정이 아니었다(3단계는 합의 목록을 따랐고 4단계는 모양 맞추기). 다시 보니 `const_table`만 `table` 경로에서 `min_const`/`max_const`를 조용히 무시했다(`candidates`·`analyze`는 AND). 선택지 A(상수 범위 전부 삭제)·B(남기고 둘 다 적용)·C(그대로) 중 B.
- `const_table`의 `table` 경로도 상수 범위를 적용하고, 세 도구 설명과 report `SKILL.md`를 규칙 하나로 맞췄다. 5단계("`analyze`에서 상수 범위 빼기")는 하지 않는다.
- 평가 중 Anthropic API 크레딧이 떨어져 한 번 끊겼다(400 "credit balance is too low"). 운영 `LLM_PROVIDER`도 claude라 그동안 운영 봇도 답하지 못했을 것이다. 사용자가 채운 뒤 다시 돌렸다.
- 평가(`--repeat 3`): 시나리오 54건 실패 0("레벨 14 마스터 랭크 분포"도 3/3 `find_songs → analyze`). examples 실패 19는 이전과 같은 오해석 + "라미아 채보 링크" 1/3 도구 없음. 신곡 상수표 그림에서 모델이 없는 도구 이름(`table_image`, `table_image_table_image`)을 먼저 불렀다가 바로잡은 경우가 2건 보였다.

## 약점 탐색 (질문 339개 × 3회, Haiku 5.5, 비용 약 $0.95)
- 임시 실행기로 `scripts/eval_agent.py`의 배선을 그대로 쓰고 질문마다 새 플레이어·채널로 돌렸다. 평가 플레이어는 기록·폴더가 없고 서버(guild) 밖이라, 기록·폴더가 있어야 이어지는 흐름(베스트→그림, 폴더→분석, `only_played`, admin 서버 설정)은 판정할 수 없었다 — 기록·폴더를 갖춘 평가 플레이어가 필요하다.
- 확인된 약점(다시 확인용 수치):
  - **상대 날짜**: 모델이 오늘 날짜를 모른다(프롬프트에 날짜가 없다). "12월 말까지", "다음 주 금요일까지", "3개월 안에" 같은 목표가 22/36 실패(연도·날짜를 되묻는다). 절대 날짜는 0/12 실패.
  - **없는 도구 이름**: 그림을 그릴 때 27번 중 11번 `table_image`(없음)를 먼저 부르고 오류를 받은 뒤 `image_table_image`로 다시 불렀다.
  - **모호한 "계정 끊어줘"·"계정 해제해줘"**: 6/6 세가 로그아웃을 바로 실행했다. 멘션 경로는 `confirm="always"` 도구도 확인 없이 실행한다(2026-10-18 결정). "연결 해제"·"디코 부계정 끊고 싶어"는 맞게 도구 없이 안내했다.
  - **약속 vs 기억**: "기억해 줘"·"잊지 마"가 붙으면 약속이어도 `remember`(6/6). "다음엔 꼭 ○○ 할 거야"는 목표를 권하며 도구 없이 끝(3/3). "약속"·"~하기로 하자"·"다음 겜플 때 ~칠게"는 맞게 약속.
  - **후보곡 → 투두**: "후보곡 뽑아서 투두로"가 6/6 `candidates`를 부르지 않고 되묻거나 앞 표가 없다고 했다. "15.0 마스 곡들 투두로"(검색 → 투두)는 맞았다.
  - **기억으로 하는 설명**: "레이팅 계산 방식"이 2/3 도구 없이 기억으로 답했다. "오버파워가 뭔데"는 2/3 용어집 뒤에 웹 검색까지 더 했다.
  - **덜 알려진 한글 곡명**: 유명곡(테스티파이·월드 뱅퀴셔·크로노미아 등)은 거의 맞지만 "카와이쿠테 고멘"·"지가 블래스트"·"완성 염상"은 흔들렸다(곡 DB에 한글 별칭이 없고 운영 DB 저장 별칭도 2개뿐이다).
  - **admin**: `set_limits`가 상한과 쿨다운을 둘 다 요구해 "월 상한 20달러로"에 쿨다운을 되묻는다(3/3). "스킬 목록이랑 상태"는 `list_capabilities`로 갔다.
  - **숫자 검사 오탐**: 되묻는 말 속 예시 숫자("예: 14.0~14.9")가 확인 안 된 숫자로 잡혀 다시 쓰기·⚠ 표시가 붙는다.
- 강했던 유형: 설정·세션·말투(오타·영어·줄임말) 0% 실패, 곡 값 3%, 검색 7%, 상수표·분석은 평가 환경 탓 실패를 빼면 거의 통과.
