# 유니 스킬: memory

Oct 9, 2026 · @astrove

유니가 플레이어에 대해 기억한 내용을 보고, 지우고, 자동 저장을 끄는 스킬이다. 메모리의 저장, 자동 요약, 프롬프트 주입은 코어가 하고, 이 스킬은 그 내용을 플레이어가 통제하는 창구다. 자동 저장은 가끔 틀린 내용을 기억하므로 이 스킬은 반드시 둔다.

## 개요

```yaml
name: memory
description: 유니가 나에 대해 기억하는 내용을 보여 주고, 지우고, 자동으로 기억하는 것을 끄거나 켠다.
examples:
  - 나에 대해 뭐 기억해?
  - 내가 왼손 약하다는 거 잊어 줘
category: 메모리
game: common
version: 1
services: [memory]
```

태그 조건은 없다.

## 메모리의 모양 (코어가 정함)

- 플레이어마다 텍스트 한 덩어리, 상한 1,500자다. 게임별 구획을 두고, 호칭 같은 공용 사실은 구획 밖에 둔다.
- 저장 대상은 호칭, 목표, 약한 패턴, 선호하는 답변 길이처럼 잘 변하지 않는 게임 관련 사실이다. 레이팅과 점수처럼 변하는 값과 게임과 무관한 개인사는 저장하지 않는다.
- 본인이 쓴 메시지에서만 뽑는다. 남이 그 사람에 대해 한 말과 농담은 넣지 않는다.
- 자세한 규칙은 코어 문서의 "플레이어 메모리" 절을 따른다.

## 도구

| 함수 | 하는 일 | 인자 | 슬래시 | display | confirm |
| --- | --- | --- | --- | --- | --- |
| `view` | 내 메모리 전문을 본인에게만 보여 줌 | 없음 | `/메모리 보기` | required | never |
| `forget` | 지정한 내용 또는 전체 삭제 | `what`(없으면 전체) | `/메모리 지우기` | optional | bulk |
| `set_auto` | 자동 저장 켜기·끄기 | `on: bool` | `/메모리 자동저장` | optional | never |

- `view`는 채널에서 불러도 본인에게만 보이는 메시지나 DM으로 보여 준다.
- `forget`은 모델이 지울 항목을 고르되, 실제로 지울 문장을 보여 주고 지운다. 이 도구는 요청한 플레이어 자신의 메모리만 바꾼다.
- 자동 저장을 꺼도 기존 메모리는 남고 계속 프롬프트에 들어간다. 완전히 없애려면 `forget`으로 전부 지운다.
- "이거 기억해 줘"는 코어의 `remember` 도구가 처리한다. 이 스킬에는 쓰기 도구를 두지 않는다.

## 이벤트

내거나 받는 이벤트는 없다.

## 데이터

이 스킬의 테이블은 없다. 메모리는 코어의 테이블에 있고 `memory` 서비스로만 읽고 쓴다.

## 유니 지침 (SKILL.md 본문 초안)

- "뭐 기억해?"에는 `view`를 쓴다. 메모리를 채널에 읽어 주지 않는다.
- 지울 내용이 애매하면 어느 문장인지 확인하고 지운다.
- 지운 내용을 다시 기억하지 않는다. 코어의 요약도 지운 항목을 되살리지 않는다.

## 테스트

- 다른 플레이어의 메모리를 보거나 지울 수 없는지.
- 전체 삭제가 확인 버튼을 거치는지.
- 자동 저장을 끄면 코어의 요약이 돌지 않는지.
- 지운 항목이 다음 요약에서 되살아나지 않는지.
