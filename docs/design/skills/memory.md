# 유니 스킬: memory

Oct 9, 2026 · @astrove

유니가 플레이어에 대해 기억한 내용을 보고, 지우고, 자동 저장을 끄는 스킬이다. 메모리의 저장, 자동 요약, 프롬프트 주입은 코어가 하고, 이 스킬은 그 내용을 플레이어가 통제하는 창구다. 자동 저장은 가끔 틀린 내용을 기억하므로 이 스킬은 반드시 둔다.

## 개요

```yaml
name: memory
description: 유니가 나에 대해 기억하는 내용을 보여 주고, 지우고, 자동으로 기억하는 것을 끄거나 켠다.
examples:
  - 나에 대해 뭐 기억해?
  - 내가 왼손 약하다는 거 잊어 줘
category: 메모리
game: common
version: 1
services: [memory]
```

태그 조건은 없다.

## 메모리의 모양 (코어가 정함)

- 플레이어마다 본문 한 덩어리(상한 1,500자, 한 줄에 사실 하나)와 호칭 한 칸(상한 20자)이다. 호칭은 본문과 따로 저장한다.
- 저장 대상은 호칭, 목표, 약한 패턴, 선호하는 답변 길이처럼 잘 변하지 않는 게임 관련 사실이다. 레이팅과 점수처럼 변하는 값과 게임과 무관한 개인사는 저장하지 않는다.
- 본인이 쓴 메시지에서만 뽑는다. 남이 그 사람에 대해 한 말과 농담은 넣지 않는다.
- 자세한 규칙은 코어 문서의 "플레이어 메모리" 절을 따른다.

## 도구

| 함수 | 하는 일 | 인자 | 슬래시 | display | confirm |
| --- | --- | --- | --- | --- | --- |
| `view` | 내 메모리 전문(호칭 포함)을 본인에게만 보여 줌 | 없음 | `/메모리 보기` | required | never |
| `forget` | 지정한 내용 또는 전체 삭제 | `what`(없으면 전체) | `/메모리 지우기` | optional | bulk |
| `set_auto` | 자동 저장 켜기·끄기 | `on: bool` | `/메모리 자동저장` | optional | never |

- `view`는 슬래시에서는 본인에게만 보이는 메시지로, 멘션에서는 DM으로 보여 준다(코어가 멘션 응답의 `ephemeral` 표시물을 DM으로 보낸다). 모델에는 줄 수만 돌려주고 전문은 주지 않는다.
- `forget`의 `what`은 지울 줄의 내용이다. 코드가 줄 단위로 찾아(같은 줄이거나 한쪽이 다른 쪽을 포함) 지우고, 지운 줄을 `forgotten`에 더한다(호칭은 더하지 않는다). 호칭을 지우려면 `what`에 "호칭"이나 호칭 자체를 준다. 찾지 못하면 현재 줄 목록을 모델에게 에러로 돌려주어 다시 고르게 한다. 전체 삭제(`what` 없음)는 본문·호칭을 모두 비우고 대기 중인 요약도 버린다. 이 도구는 요청한 플레이어 자신의 메모리만 바꾼다.
- 자동 저장을 꺼도 기존 메모리는 남고 계속 프롬프트에 들어간다. 완전히 없애려면 `forget`으로 전부 지운다.
- "이거 기억해 줘"는 코어의 `remember` 도구가 처리한다. 이 스킬에는 쓰기 도구를 두지 않는다.

## 이벤트

내거나 받는 이벤트는 없다.

## 데이터

이 스킬의 테이블은 없다. 메모리는 코어의 테이블에 있고 `memory` 서비스로만 읽고 쓴다.

## 유니 지침 (SKILL.md 본문 초안)

- "뭐 기억해?"에는 `view`를 쓴다. 메모리를 채널에 읽어 주지 않는다.
- 지울 내용이 애매하면 어느 문장인지 확인하고 지운다.
- 지운 내용을 다시 기억하지 않는다. 코어의 요약도 지운 항목을 되살리지 않는다(`forgotten`을 요약 프롬프트에 넣는다).

## 테스트

- 다른 플레이어의 메모리를 보거나 지울 수 없는지.
- 전체 삭제가 확인 버튼을 거치는지.
- 자동 저장을 끄면 코어의 요약이 돌지 않는지.
- 지운 항목이 다음 요약에서 되살아나지 않는지.

## 구현 결정

- **2026-10-19 (12단계 Part 1)**: 도구 셋과 슬래시는 위 표 그대로다. `forget`은 `confirm="bulk"`라서 지울 항목이 2개 이상이면 슬래시는 확인 버튼을 거치고, 멘션은 요청 자체를 확인으로 보고 바로 지운다(`core/agent.py`의 기존 결정). `set_auto`의 인자는 `on: bool`이다.
- `view`는 표시물에 `private=True`를 켠다. 슬래시는 `ephemeral`로 본인에게만 보이고, 멘션은 코어(`core/mention.py`)가 채널 답장에 붙이지 않고 DM으로 보낸다. DM을 못 보내면 그 사실을 답에 덧붙인다(`PRIVATE_DM_FAILED_MESSAGE`). 모델에는 줄 수만 `data`로 주고 전문은 주지 않는다.
- 호칭 칸은 `forget`의 `what`이 `호칭`이거나 호칭 값일 때 지운다(항목 표기는 `호칭: ○○`).

- **관리 대화 제외 (2026-10-20)**: admin 태그가 필요한 도구를 부른 턴은 자동 요약 대기 목록에 넣지 않는다. 명시적 `remember`는 그대로 저장한다.
