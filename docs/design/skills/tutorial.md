# 유니 스킬: tutorial

2026-11-22 · 사용자 요청

처음 쓰는 사람이 사용법을 물을 때, 허락을 받고 DM에서 대화형 튜토리얼을 진행한다. 주 게임·로그인 여부·자주 쓸 기능을 묻고, 기본 명령(`/로그인`·`/동기화`·`/설정`·`/연결`, 멘션으로 시키는 레이팅표·베스트·곡 검색)을 알려 주고, 질문에는 답한다. 끝나면 알게 된 것을 압축해 개인 메모리에 넣는다.

## 개요

```yaml
name: tutorial
category: 사용법
games: []
version: 1
services: [players, notify, yuni]
```

태그 조건은 없다. 본인에게만 DM을 열고 본인의 주 게임만 바꾼다.

## 흐름

1. 사용법을 물으면 모델이 먼저 "DM으로 알려 줘도 돼?"를 묻는다. **멘션 경로에는 확인 버튼이 없어**(`confirm="always"`도 멘션에서는 자동 확인, 2026-10-18 결정) 이 허락은 말로 받는다. 분명한 허락이 온 뒤에 `tutorial_start`를 부른다. 처음부터 "DM으로 튜토리얼 해 줘"라고 했으면 그것이 허락이다. 구체적인 질문("동기화는 어떻게 해?")에는 튜토리얼 없이 답한다.
2. `tutorial_start`: `notify.open_dm_thread`(세션 후기와 같은 부품)로 본인 대표 계정 DM에 대화를 연다. 첫 말은 `yuni.line`이 쓰고 끝내기 버튼이 붙는다. 이미 열려 있거나 DM이 막혀 있으면 에러로 안내한다. 무응답 10분 뒤 끝났는지 묻고, 5분 더 없으면 닫는다.
3. DM 대화의 지침(`guidance`)은 코드가 만든다. 순서는 ①주 게임 → ②로그인 → ③자주 쓸 기능 → ④기본 명령 안내(**필수**: ③의 답이 "다"·"몰라"처럼 애매해도 건너뛰지 않고, 알려 줄 명령을 짧은 목록으로 한 메시지에 보여 준다) → ⑤"더 궁금한 거 있어?" → ⑥플레이어가 끝이라고 한 뒤에만 마무리. ④와 같은 턴에 닫지 않고 안내를 미루지 않는다. 그 밖에 말 줄이기, 질문 우선 답변, 아는 상태(주 게임·`sega-linked` 태그)는 다시 묻지 않기, 알려 줄 명령 목록(실제 등록된 이름만).
4. 주 게임을 말하면 `tutorial_set_main_game(game: GameRef)`로 `players.main_game`에 저장한다(`/설정`의 주 게임과 같은 값).
5. 마무리 전에 모델이 `remember`로 한 줄에 사실 하나씩 두세 줄을 저장하고 `end_conversation`을 부른다. 첫 인사에서 "요약해서 기억해 둔다"고 알린다. 대화가 닫히면 코어가 사용자 글을 메모리 요약 대기열에도 넣는다(자동 저장이 켜져 있을 때).

## 도구

| 도구 | 하는 일 |
| --- | --- |
| `tutorial_start` | DM 튜토리얼 대화를 연다. 허락을 받은 뒤에만 부른다 |
| `tutorial_set_main_game` | 본인의 주 게임을 저장한다 |

## 결정과 한계

- 처음 보는 사람에게 유니가 먼저 DM을 걸지 않는다(멘션·답장·버튼에만 반응하는 하드 제약). 사용법을 물을 때만 시작한다.
- 새 분류 `사용법`을 `core/manifest.py`·`00-core.md`에 더했다.
- 슬래시 명령은 전역 등록이라 DM에서도 쓸 수 있다. 실기 확인 필요: DM에서 `/로그인`이 뜨는지.
