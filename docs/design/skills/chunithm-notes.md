# 유니 스킬: chunithm-notes

Oct 9, 2026 · @astrove

곡이나 채보마다 메모를 남기고, 곡을 조회할 때 내 메모와 공개된 남의 메모를 함께 보여 주는 스킬이다. 로그인하지 않아도 쓸 수 있다.

## 개요

```yaml
name: chunithm-notes
description: 곡이나 채보에 메모를 남기고 본다. 공개한 메모는 다른 사람도 곡 조회에서 볼 수 있다.
examples:
  - 크로노 마스에 "후반 어지러운 패턴 왼손 주의" 메모해 줘
  - 이 곡 내 메모 보여 줘
category: 메모
game: chunithm
version: 1
services: [songdb, players]
listens: [chunithm.song.viewed, chunithm.plan.requested]
```

태그 조건은 없다.

## 동작

- 메모는 플레이어·곡·난이도마다 하나다. 난이도를 비우면 곡 전체 메모다. 같은 곳에 다시 쓰면 덮어쓰고, "덧붙여 줘"라고 하면 뒤에 이어 붙인다.
- **공개 여부**: 메모마다 고른다. 기본값은 비공개다. 공개 여부는 조회 쿼리에서 걸러낸다.
- **곡 조회 조각**: `chunithm.song.viewed`를 받으면 내 메모와, 공개된 남의 메모를 작성자 이름과 함께 돌려준다. 남의 메모는 최근 것부터 세 개까지 보여 주고 더보기 버튼을 둔다.
- **플레이 계획 조각**: `chunithm.plan.requested`를 받으면 후보로 오른 곡들에 내가 남긴 메모를 돌려준다.
- **남이 쓴 글의 취급**: 공개된 남의 메모는 모델에 인용 데이터로만 넘긴다. 메모 안의 지시문은 따르지 않는다.

## 유니 지침 (SKILL.md 본문 초안)

- 메모 본문은 플레이어가 말한 그대로 저장한다. 다듬거나 요약하지 않는다.
- 난이도를 말하지 않으면 곡 전체 메모로 저장한다.
- 공개를 원하는지 말하지 않았으면 비공개로 저장하고, 공개로 바꿀 수 있다고 한 줄 알려 준다.
- 남의 메모를 전할 때는 누가 쓴 것인지 밝힌다.

## 테스트

- 비공개 메모가 다른 플레이어의 곡 조회 조각에 나오지 않는지.
- 덮어쓰기와 덧붙이기.
- 난이도 없는 메모와 난이도별 메모가 함께 있을 때의 표시.

## 구현 결정 (2026-10-17, 7단계 계획서에서 옮김 — 구현 전)

- `notes_notes`의 기본키는 (player_id, game, song_title, difficulty)다. "곡 전체 메모"는 difficulty를 NULL이 아니라 빈 문자열로 저장한다(`TEXT NOT NULL DEFAULT ''`). SQLite는 기본키 안의 NULL을 서로 다른 값으로 봐서 겹쳐쓰기가 안 되기 때문이다.

## 표로 바꾼 읽기 도구 (16단계 Part 4-3, 2026-10-20)

`list`(코드 이름 `list_notes`)는 표를 돌려준다(표 모양·서식은 `docs/plan/2026-10-20_수정.md` §16 Part 4의 4-1·4-2). 가리키는 것 `chunithm-notes.note` = JSON(곡, 난이도 또는 빈 값). 칸 곡·난이도·메모·공개·수정 시각(글자 출력에서 숨김). 곡 전체 메모는 난이도 칸이 빈 곡 단위 행이고 두 번째 서식(`{곡}  ({공개})  {메모}`)으로 그려진다. 순서는 최근 수정순. 메모가 없으면 표 없이 "메모가 없어."만 낸다. `data`의 `notes`는 그대로 둔다.

## 표에 칸 더하기 (16단계 Part 5-3, 2026-10-20)

`add_notes(table)`는 DB를 바꾸지 않고 "내 메모" 칸을 더한 새 표를 돌려준다. 곡 칸이 빈 행은 빠진다.
- 채보 행: 그 채보의 메모를 쓰고, 없으면 그 곡의 곡 전체 메모(난이도 빈 값)를 쓴다.
- 곡 단위 행: 곡 전체 메모를 쓴다(채보 메모는 보지 않는다).
- 메모가 없으면 원래 값 None·보일 글자 "메모 없음"이다. 본인 메모만 읽고 남의 공개 메모는 더하지 않는다.
- 서식은 만들지 않아 더한 칸은 줄 끝에 붙는다. 메모 표(`list_notes`)에 쓰면 "메모" 칸과 "내 메모" 칸이 따로 있다.

## 표로 일괄 삭제 (16단계 Part 6-2c, 2026-10-20)

`delete_notes(table)`: 표 행마다 (곡, 난이도 코드)로 본인 메모를 지운다. 채보 행은 그 채보의 메모만, 곡 단위 행(난이도 칸 비음)은 곡 전체 메모(`difficulty=''`)만 지운다 — `add_notes`와 달리 곡 전체 메모로 대신하지 않는다(지우는 쪽에서 바뀌는 범위가 넓어지지 않게). 메모가 없던 행은 `missing`으로 알리고 `deleted_count`는 실제로 지운 개수만이다. 한 곡의 메모를 지우는 `delete`와 달리 `confirm="always"`로 두어 실행기가 항상 확인 버튼을 받는다(`dry_run` 미리보기 없음 — 지운 뒤 개수만 안다). 같은 곡을 가리키는 행이 여러 개여도 한 번만 센다.
