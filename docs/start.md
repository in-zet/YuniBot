# 세션 시작 체크리스트

1. **`CLAUDE.md`** — 자동 로드됨. 스택·범위·하드 제약이 여기 있다.
2. **`docs/doc-guide.md`** — 무엇을 어디에 기록하는지. 이후 모든 문서 작업의 기준.
3. **`docs/plan.md`** — 범위, 작업 단계, 리스크. **지금 어느 단계인지 여기서 확인.**
4. **`docs/INDEX.md`** — 경로 색인. 뭘 건드리면 안 되는지.
5. **`progress/` 최신 날짜 파일 1개** — 직전 세션 흐름과 **"다음 시작점"**(맨 아래).
6. 작업할 영역의 설계서는 **필요한 절만** 읽는다. `docs/design/00-core.md`(약 64KB)를 통째로 읽지 말고 `## ` 제목으로 찾아 그 절만 본다. 스킬 작업이면 `docs/design/skills/<스킬>.md` 전체와 끝의 "구현 결정" 절.
7. `/clear` 직후라면 `temp/context_snapshot.md`가 있는지 확인한다(있으면 읽되, 최신이 아닐 수 있으므로 `progress/` 최신 파일과 대조한다).

읽은 뒤에는 현재 단계와 다음 시작점을 두세 줄로 말하고 사용자 지시를 기다린다.
