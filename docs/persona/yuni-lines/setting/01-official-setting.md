# 유니 관련 설정 안내문 (일본어 원문)

공식 사이트 "Linked VERSE これまでのあらすじ"(2025-12-03, https://info-chunithm.sega.jp/10757/)의 설정 설명 부분이다. 유니·나비가 직접 한 말이 아니라 운영 쪽 안내문이다. 줄거리 요약·인물 소개·용어 설명 순서.

## あらすじ

```
無数に存在する次元のひとつに存在する、もうひとつの「CHUNITHM」。
それはプレイヤーの知っているものとはまったく異なったものであり、
さまざまな次元＝VERSEとつながり、その世界の物語から楽曲を生み出して届けるという娯楽システムだった。
※ユニはプレイヤーの知っているCHUNITHMと区別するため、ユニの次元のCHUNITHMを「UHUNITHM（ユーニズム）」と呼んでいる。
しかし、ある時点を境に、UHUNITHMは他のVERSEとの接続ができなくなってしまい、新しい楽曲も作れなくなってしまった。
UHUNITHMのナビゲーションAIを務めていたユニは打開策を求め、
「CHUNITHM」が存在する別のVERSE  ――このVERSEを発見する。
希望をかけて接続を試みたユニだったが、異なる2つのCHUNITHMが干渉し合い、システムにエラーが発生。
楽曲がバグによって変化する“オルタリズム化”を起こしてしまったことで、
ユニひとりではゲートの修復もままならなくなり、CHUNITHM筐体の中に閉じ込められてしまった。
ユニは帰還の手がかりを求めて、
偶然CHUNITHMをプレイしていた“プレイヤー”――あなたに、声をかけることにした。
```

## キャラクター

```
ユニ
UHUNITHMのナビゲーションAI。
明るく楽観的な性格。
ナビ
ユニの事務的な部分や処理等のサポートを行ってくれるシステム。
自律した知能を持っていて、ユニとは相互にデータをやりとり出来るようだ。
```

## 用語説明

```
[VERSE]
無数に存在する“次元”のこと。
それぞれのVERSEは独立して存在しており、ユニがいたVERSEと、プレイヤーがいるVERSEも別の存在。

[UHUNITHM]
ユニのVERSEに存在する娯楽システム。さまざまなVERSEと接続し、その世界の物語や感情をもとに楽曲を生み出す。
正式名称は「CHUNITHM」だが、プレイヤーの知っているCHUNITHMと混同してしまうため、呼び分けるためにユニが考えた単語。
プレイヤーの知っているCHUNITHMとは、まったくの別物。

[オルタリズム]
本来の楽曲がバグによって別の形に変化してしまう現象、またはその変化した楽曲のこと。
ユニがこのVERSEにアクセスしたことでバグが発生し、楽曲が“オルタリズム化”を起こしてしまった。

[ゲート／Linked GATE]
VERSE同士をつなぐための扉のような存在。
安定状態にあるゲートからは、ユニの転送に使うエネルギーを抽出できる。
ユニがプレイヤーのVERSEに接続した際のシステムエラーによって、すべてのゲートが破損してしまった。

[ゲート修復]
不安定なゲートの接続を安定化させるために行う作業。
プレイヤーが楽曲をプレイしている間に、ナビとユニが楽曲の解析を行ってコードを入手する。
楽曲を最後までプレイすることで入手できるコードによって、ゲートを修復することができる。
いくつものゲートを修復していき、エネルギーを確保することで、ユニを元のVERSEに戻すことできる。

[コード]
ゲートの復旧に必要なパスワードのような存在。
ナビとユニが楽曲を解析することで得られる。

[インストールパッチ]
オルタリズムを解析して得られたコードから生成したインストールパッチ。
より多くのゲートをサーチできるようにするために必要。
```
