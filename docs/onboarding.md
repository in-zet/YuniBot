# 작업 방식 전환 안내 (1회성)

2026-10-18에 이 저장소의 작업 방식을 바꿨다. 이 문서는 바뀐 뒤 처음 여는 세션에서 **한 번만** 쓰고 지운다.

## Claude가 할 일 (순서대로)

1. 아래 "사용자에게 전할 내용"을 한글로 짧게 정리해 전한다. 표와 목록을 그대로 읊지 말고, 사용자가 바로 따라 할 수 있게 "앞으로 이렇게 말하면 된다" 위주로 말한다.
2. superpowers 플러그인이 꺼졌는지 사용자에게 확인을 부탁한다. Claude는 플러그인을 직접 끄지 못한다. 사용자가 `/plugin` 메뉴에서 superpowers를 Disable하거나 Uninstall하면 된다.
   저장소 루트에 `.superpowers/` 폴더(옛 작업 기록)가 남아 있으면, 지워도 되는지 물어본 뒤 지운다.
3. 사용자가 안내를 확인하면 아래 정리를 한다.
   - `CLAUDE.md`의 "1회성 안내" 절을 지운다.
   - 이 파일(`docs/onboarding.md`)을 지운다.
   - `docs/INDEX.md`에서 이 파일의 행을 지운다.
   - `progress/` 오늘 날짜 파일에 "~~온보딩 안내~~ 완료, 안내 문서 삭제" 한 줄을 남긴다.
   - 커밋할지 사용자에게 묻는다(커밋은 요청할 때만 한다).
4. 그다음부터는 평소대로 `docs/start.md`를 따른다.

### 앞으로의 작업 흐름

- **세션 시작**: 새 세션에서 "CLAUDE.md 읽고 대기"라고만 하면 된다. `CLAUDE.md`는 자동으로 로드되고, Claude가 `docs/start.md` 순서대로 필요한 문서(계획, 색인, 최신 진행 기록)만 읽은 뒤 현재 단계와 다음 시작점을 말하고 기다린다. 바로 작업을 시켜도 된다.
- **작업 지시**: "plan.md 7단계 Part 2 진행해"처럼 `docs/plan.md` §4의 체크 항목 하나를 시킨다. Claude는 무엇을 어떻게 할지 채팅으로 짧게 말하고, 승인하면 구현한다. 그사이 바꾼 곳의 시험만 돌린다.
- **멈춤과 보고**: 작업 단위 하나가 끝나면 Claude가 멈추고 기다린다. 보고는 판단이 필요한 것만 한다: 결정이 필요한 갈림길, 디스코드에서 직접 확인할 것, 막혀서 멈춘 지점. 막히면 추측으로 우회하지 않고 "무엇을 하려다 / 무엇이 막혔고 / 확인된 사실 / 선택지"로 보고한다.
- **마무리**: 작업 단위가 끝나면 Claude가 `docs/end.md`를 따른다. 전체 시험·린트·타입 검사를 돌리고, 임시 파일을 지우고, `progress/YYYY-MM-DD.md`에 한두 줄 로그와 "다음 시작점"을 남기고, 바뀐 결정을 설계서나 `plan.md`에 반영한다. 다음 세션은 이 "다음 시작점"에서 이어 간다.
- **커밋**: 이제 **요청할 때만** 한다. 예전처럼 작업이 끝날 때마다 자동으로 커밋·병합하지 않는다. "커밋해"라고 하면 그 작업 단위만 묶어 커밋하고, `git push`는 따로 확인받는다.
- **긴 세션**: 컨텍스트가 길어지면 `/clear` 전에 "스냅샷 저장해"라고 한다. Claude가 `temp/context_snapshot.md`에 진행 상황을 적어 두고, `/clear` 뒤에 그걸 읽고 이어 간다. `/context`로 무엇이 컨텍스트를 차지하는지 가끔 확인하면 좋다.
- **기억**: Claude 기본 메모리를 쓰지 않는다. 남길 것은 전부 저장소 문서(`CLAUDE.md`, `docs/`, `progress/`)에 적으므로, 다른 PC나 다른 세션에서도 그대로 이어진다.

### 이번 전환에서 바뀐 것

- `docs/superpowers/` 삭제. 계획서의 결정 사항은 설계서(각 스킬 문서 끝 "구현 결정" 절, `00-core.md`)와 `docs/plan.md`로 옮겼다. 원본이 필요하면 git 이력에 있다(`progress/2026-10-18.md`에 꺼내는 명령).
- 설계서를 코드에 맞게 고쳤다. 이벤트 내용 형식(dict), PlayerRef 범위, 부여 태그의 슬래시 표시, songdb 갱신 주기 등.
- `README.md`를 새로 썼고 `.gitignore`·`.dockerignore`에 남아 있던 옛 항목을 정리했다.
- 기능 코드는 바꾸지 않았다. 주석, 그리고 `admin` `/관리 상한` 도구 설명(모델에게 가는 문구)의 낡은 한 줄만 고쳤다.
